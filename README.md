# Fang Viper size guide

Static size guide for fangviper.com, served by GitHub Pages at https://size.fangviper.com/.

- index.html: page markup
- assets/ui.js: size data (add new products in PRODUCTS), units, fit finder
- assets/fit3d.js: 3D fit model (three.js from jsDelivr), built from the cm specs of the chosen size
- assets/site.css: styles (black, white and greys only)

Link to a size directly: https://size.fangviper.com/?size=M&unit=cm
